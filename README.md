# Atividades Java

##Atividade 1 :Conta Bancária

Crie uma classe:

```java
ContaBancaria
```

Atributos privados:

```java
titular
saldo
```

Métodos:

```java
depositar()
sacar()
consultarSaldo()
```

Regras:

- Não permitir saque maior que saldo.
    
- Não permitir depósito negativo.
    

### O que avalia

- Encapsulamento
    
- Getters e Setters
    
- Regras de negócio
