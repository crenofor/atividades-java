# Atividades Java

# Nível 1 — Fundamentos

## Desafio 1: Sistema Bancario

Crie uma classe:

```java
ContaBancaria
```

Atributos privados:

```java
titular
saldo
```

Métodos:

```java
depositar()
sacar()
consultarSaldo()
```

Regras:

- Não permitir saque maior que saldo.
    
- Não permitir depósito negativo.
    

### O que avalia

- Encapsulamento
    
- Getters e Setters
    
- Regras de negócio

# Nível 2 — Herança

## Desafio 2: Sistema de Funcionários

Classe base:

```java
Funcionario
```

Atributos:

```java
nome
salario
```

Método:

```java
calcularBonus()
```

Classes filhas:

```java
Gerente
Programador
Estagiario
```

Cada uma possui bônus diferente.

Exemplo:

```java
Gerente = 20%
Programador = 10%
Estagiario = 5%
```

### O que avalia

- Herança
    
- Sobrescrita de métodos
